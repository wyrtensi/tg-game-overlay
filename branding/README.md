Brand assets: `icon.svg` (app icon source, 1024x1024), `icon-1024.png` (its render, input for the Tauri icon set), `banner.svg` / `banner.png` (README hero and GitHub social preview, 1280x640). Banner text is converted to outlines, set in Chakra Petch (SIL Open Font License 1.1, (c) The Chakra Petch Project Authors, from github.com/google/fonts), so the PNG does not depend on installed fonts.
Regenerate the PNGs from the SVGs with any renderer that supports SVG masks and gradients, for example `@resvg/resvg-js` (`new Resvg(svg, { fitTo: { mode: 'width', value: 1024 } }).render().asPng()`).
Regenerate the Tauri icon set from the repo root with `npx tauri icon branding/icon-1024.png`, then delete the generated `src-tauri/icons/android` and `src-tauri/icons/ios` folders (the app is Windows-only).
